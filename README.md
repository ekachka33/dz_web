# dz_web
# Проект веб-приложения с использованием Bootstrap

Это веб-приложение создано для тестирования функциональности, основываясь на прототипах страниц. Приложение обрабатывает GET-запросы и возвращает страницу "Контакты", используя HTML-документы, стилизованные с помощью Bootstrap. Проект также демонстрирует работу с удалёнными репозиториями для загрузки файлов.

## Описание

Проект состоит из двух частей:
1. **Задание 1**: Сборка HTML-документов с использованием Bootstrap, которые представляют собой страницы с базовой структурой и стилями.
2. **Задание 2**: Создание веб-приложения, которое на любой GET-запрос возвращает страницу «Контакты». Файлы подключаются с удалённого репозитория, и сервер возвращает страницу с правильным типом содержимого `text/html`.

## Технологии

- **HTML/CSS** — для создания структуры и стилей страниц.
- **Bootstrap** — для добавления готовых стилей и улучшения интерфейса.
- **Python** — язык программирования для создания сервера.
- **Flask** — веб-фреймворк для обработки HTTP-запросов.
